## プロジェクト概要

本プロジェクトは、中医基礎理論、弁証論治、方薬応用、鍼灸推拿、婦人科・小児科、温病・傷寒、腫瘍治療、体質識別、中西医結合などの中核的領域を系統的に統合し、**172の主要臨床スキル**を20のカテゴリーに分類しています。

**対象読者**：中医師、中西医結合医、医学生、中医药研究者、養生保健従事者

**参考教科書**：人民衛生出版社『中医学』第10版（全国高等学校五年制本科臨床医学専業計画教材）
